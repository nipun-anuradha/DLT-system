## 1. Getting Started

The DLT System is a web-based platform designed to streamline IT support requests and communication within the organization. This manual will guide you through all the features available to users.

**System Requirements:**
- Modern web browser (Chrome, Firefox, Edge, Safari)
- Active internet connection
- Valid employee credentials

## 3. Create Account

**[Insert Create Account Screenshot Here]**

### Registration Steps:

1. Click **"Create Account"** on the login page
2. Fill in the required information:
   - **Full Name** - Enter your complete name
   - **Employee No** - Enter your employee number (e.g., 33xx)
   - **Username** - Choose your login username (e.g., user@dlt.lk)
   - **Password** - Create a password (minimum 3 characters)
   - **Confirm Password** - Re-enter your password
   - **Mobile Number** - Enter your 10-digit mobile number
   - **Branch** - Select your branch from the dropdown
   - **Department** - Select your department from the dropdown
3. Click **"Create Account"** to submit
4. Click **"Cancel"** to close without saving

> **Note:** All fields marked with * are required.

## 5. IT Support Tickets

**[Insert Tickets Page Screenshot Here]**

This page displays all your support tickets and their current status.

### Statistics Cards:

- **Total Tickets** - Total number of tickets you've created
- **Open Tickets** - Tickets waiting for IT response
- **In Progress** - Tickets currently being worked on
- **Closed Tickets** - Resolved tickets

### Ticket Table:

Each ticket shows:
- **ID** - Unique ticket number (e.g., #4)
- **Subject** - Brief description of the issue
- **Priority** - Low, Medium, or High
- **Status** - Open, In Progress, or Closed
- **Created** - Date ticket was created
- **Last Updated** - Time since last activity
- **Actions** - Click the eye icon to view details

### Filtering Options:

1. **Search Bar** - Search tickets by ID, subject, or keyword
2. **My Tickets** - Filter to show only your tickets
3. **All Status** - Filter by status (Open, In Progress, Closed)

### Creating a New Ticket:

Click the green **"+ Open New Ticket"** button in the top right corner.

## 6. Creating a New Ticket

**[Insert New Ticket Screenshot Here]**

### Steps to Submit a Support Request:

1. Navigate to **Tickets** → Click **"Open New Ticket"**
2. Fill in the ticket details:

| Field | Description |
|-------|-------------|
| **Subject** | Briefly summarize the issue (e.g., "Can't log into the System") |
| **Category** | Select the type of issue (Hardware Issue, Software Issue, etc.) |
| **Priority Level** | Select urgency: Low (General Inquiry), Medium, or High |
| **Description** | Provide detailed steps to reproduce the issue |
| **Attachment** | (Optional) Upload supporting files (PNG, JPG, PDF, DOC - Max 10MB) |

3. Click **"Create Ticket"** to submit
4. Click **"Discard"** to cancel

### Ticket Information:

- **Ticket ID** - Auto-generated after submission
- **Date Created** - Automatically set to current date
- **Status** - Initially set to "Open"

> **Tip:** Provide as much detail as possible in the description to help IT resolve your issue faster.

## 7. Viewing Ticket Details

**[Insert Ticket Detail Screenshot Here]**

This page allows you to communicate with IT support about your ticket.

### Ticket Header:

- **Ticket ID** - Your ticket number (e.g., #4)
- **Status Badge** - Current status (Open, In Progress, Closed)
- **Subject** - Your ticket subject
- **Awaiting Response** - Shows if waiting for IT response

### Message Area:

- Messages are displayed in a chat format
- **Your messages** appear on the right (green bubbles)
- **IT Support messages** appear on the left
- Each message shows the time it was sent

### Sending Messages:

1. Type your message in the text box at the bottom
2. Press **Enter** to send, or **Shift + Enter** for a new line
3. Click the **paperclip icon** to attach files
4. Click the **send button** (arrow icon) to send

### Closing a Ticket:

- Click the **"✕ Close Ticket"** button when your issue is resolved
- Closed tickets cannot receive new messages

## Quick Reference Guide

### Common Actions:

| Action | How To |
|--------|--------|
| Login | Enter username and password, click Login |
| Create Account | Click "Create Account" on login page |
| View Dashboard | Login → automatically redirected |
| Open New Ticket | Dashboard → IT Support → Access Portal → Open New Ticket |

| Reply to Ticket | Tickets → Click eye icon → Type message → Press Enter |

| Logout | Click profile icon → Logout |

### Ticket Priority Guidelines:

| Priority | When to Use |
|----------|-------------|
| **Low** | General inquiries, non-urgent requests |
| **Medium** | Issues affecting your work but with workarounds |
| **High** | Critical issues blocking your work completely |
